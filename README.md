# Research Monitor

Live dashboard tracking CAR-T, BiTE / T-cell engagers and autologous HSCT in autoimmune disease:
recent PubMed papers, ClinicalTrials.gov trials, Europe PMC preprints, and cumulative
publication and patient charts by calendar quarter.

**Open the dashboard:** https://ragunnar.github.io/research-monitor/

- The page is a single self-contained file (`index.html`) that queries PubMed, ClinicalTrials.gov
  and Europe PMC directly from the browser.
- EU CTIS trials are not merged on this hosted version (the CTIS API blocks browser requests).
- Patient counts for CAR-T and BiTE come from a de-duplicated registry compiled by
  Ragnar Gunnarsson, MD/PhD (status 1 July 2026).
